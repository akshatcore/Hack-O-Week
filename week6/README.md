# Week 6 - Array and Object Methods

## Overview
Practice JavaScript array and object methods with a student list example.

## Files
- `index.html` - page load and layout.
- `style.css` - simple styles for the student list.
- `script.js` - demos `map`, `filter`, `reduce`, `find`, `some`, and `every`.

## Learning goals
- Transform arrays with `map`.
- Filter data with `filter`.
- Aggregate values with `reduce`.
- Search and test with `find`, `some`, and `every`.
