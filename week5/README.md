# Week 5 - JavaScript Basics

## Overview
Practice modern JavaScript syntax and build a simple module-driven page.

## Files
- `index.html` - page that loads the script module.
- `style.css` - simple page styles.
- `script.js` - modern JavaScript with destructuring, template literals, and module exports.

## Learning goals
- Use `const` and object destructuring.
- Use template literals to build dynamic strings.
- Create a JavaScript module with exported functions and values.
