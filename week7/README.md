# Week 7 - Asynchronous JavaScript and Browser APIs

## Overview
Practice asynchronous JavaScript, fetch API requests, DOM updates, event handling, and localStorage.

## Files
- `index.html` - page with button and user info area.
- `style.css` - styling for the interactive section.
- `script.js` - handles fetching data, async/await, and localStorage.

## Learning goals
- Use `async/await` and error handling.
- Fetch data from a remote API.
- Manipulate the DOM with event listeners.
- Store and load data with `localStorage`.
