# Week 4 - CSS Grid and Flexbox

## Overview
Practice CSS layout techniques, responsive grids, and flexible components.

## Files
- `index.html` - sample layout page showing cards and responsive design.
- `style.css` - CSS Grid and Flexbox styles plus responsive behavior.

## Learning goals
- Build responsive layouts using CSS Grid.
- Use Flexbox for card content and alignment.
- Apply responsive design techniques with media queries.
