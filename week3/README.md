# Week 3 - HTML5 Semantics and Accessibility

## Overview
Practice HTML5 semantic elements, accessible forms, and basic accessibility best practices.

## Files
- `index.html` - sample semantic page with a contact form and accessible markup.
- `style.css` - styling for the form and page layout.

## Learning goals
- Use semantic elements like `header`, `main`, `section`, and `footer`.
- Build forms with proper `label` associations.
- Create accessible form controls and fieldsets.
